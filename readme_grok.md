# Фінальне завдання: Симуляція кидання двох кубиків методом Монте-Карло

## Мета роботи
Написати програму на Python, яка імітує велику кількість кидків двох ігрових кубиків, обчислює суми чисел, що випадають, і визначає ймовірність кожної можливої суми (від 2 до 12) за допомогою методу Монте-Карло. Порівняти отримані результати з аналітичними розрахунками.

## Реалізація
Програма `dice_monte_carlo.py` виконує наступне:

1. Генерує 1 000 000 незалежних кидків двох чесних шестигранних кубиків за допомогою `numpy.random.randint`.
2. Обчислює суму очок для кожного кидка.
3. Підраховує частоту появи кожної суми від 2 до 12.
4. Обчислює емпіричні ймовірності як відношення частоти до загальної кількості кидків.
5. Виводить порівняльну таблицю емпіричних та аналітичних значень.
6. Будує стовпчикову діаграму порівняння та зберігає її у файл `dice_probabilities_comparison.png`.

### Запуск
```bash
python3 dice_monte_carlo.py
```

## Висновки

1. **Точність методу Монте-Карло.** При великій кількості випробувань (1 000 000) емпіричні ймовірності дуже близькі до аналітичних. Найбільше відхилення становить менше 0.06 відсоткових пунктів, що є очікуваним результатом для методу Монте-Карло і свідчить про правильність як аналітичних розрахунків, так і програмної реалізації.

2. **Збіжність.** За законом великих чисел частота появи події прагне до її теоретичної ймовірності при збільшенні кількості випробувань. Отримані результати підтверджують цей закон: розподіл сум має характерну «пірамідальну» форму з максимумом на сумі 7.

3. **Правильність алгоритму.** Програмно реалізовано повний алгоритм:
   - імітація кидання двох кубиків;
   - підрахунок сум і їх частот;
   - обчислення емпіричних імовірностей;
   - порівняння з теоретичними значеннями;
   - візуалізація результатів.

4. **Практичне значення.** Метод Монте-Карло дозволяє оцінювати ймовірності навіть у випадках, коли аналітичний розрахунок ускладнений або неможливий. У даному простому прикладі він демонструє високу точність і надійність.
