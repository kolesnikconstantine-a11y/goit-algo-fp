# Звіт: Моделювання кидання ігрових кубиків методом Монте-Карло

## Огляд Проєкту
Цей проєкт присвячений визначенню ймовірностей сум чисел, що випадають при киданні двох ігрових кубиків. Для розрахунку використовується **метод Монте-Карло**, який базується на проведенні великої кількості випадкових симуляцій. Отримані результати порівнюються з теоретичними (аналітичними) розрахунками для перевірки точності методу.

## Методологія
Програмний скрипт на Python імітує від 100 до 100,000 кидків двох шестигранних кубиків. Для кожного кидка фіксується сума значень (від 2 до 12), після чого обчислюється емпірична ймовірність кожної суми.

## Висновки

На основі проведених експериментів та аналізу результатів можна зробити такі висновки:

1. **Підтвердження Закону великих чисел:** Як засвідчили симуляції з різною кількістю ітерацій, зі збільшенням кількості кидків ($N = 100,000$) емпірична ймовірність, розрахована методом Монте-Карло, асимптотично наближається до математичної. При малій вибірці ($N = 100$) спостерігались значні відхилення, тоді як при масштабній симуляції похибка не перевищує сотих часток відсотка, що свідчить про високу точність на великих об'ємах даних.
2. **Точність та надійність методу Монте-Карло:** Метод Монте-Карло виявився ефективним і надійним інструментом для оцінки ймовірностей у стохастичних моделях. Отримані практичним шляхом значення повністю корелюють з аналітичними показниками.
